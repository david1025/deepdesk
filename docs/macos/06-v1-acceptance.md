# V1 发布级验收清单

状态说明：`[ ]` = 还没有真实测试通过；下游 AI 必须将每项和实际证据对应，不得凭静态代码直接勾选。

## A. 构建与安装

- [ ] A01 XcodeGen 能生成 Xcode 工程；Xcode Debug/Release 真机编译无错误。
- [ ] A02 Apple Silicon arm64 与 Intel x86_64 构建均可启动，Universal DMG 安装可用。
- [ ] A03 Developer ID 签名 + Hardened Runtime，`spctl` 与 `stapler` 验证公证通过。
- [ ] A04 覆盖安装/移动 `.app`、重启、升级后，聊天数据库保持正常；Mac API Key 保存后跨启动恢复。

## B. 原生桌面

- [ ] B01 红黄绿、拖动、最大化、全屏、窗口尺寸恢复和分屏操作符合 Mac 习惯。
- [ ] B02 深色/浅色/跟随系统：标题栏、聊天页面、弹窗一致，系统切换可实时响应。
- [ ] B03 Cmd+, Cmd+N Cmd+Shift+N Cmd+W Cmd+Q 快捷键有效，没有与编辑器冲突。
- [ ] B04 关闭最后窗口不断开应用，Dock/菜单栏可重新打开，菜单栏退出彻底结束。
- [ ] B05 开机启动开关正确，系统设置显示状态与应用一致。
- [ ] B06 关于、更新、引导、文件提示为优雅原生弹窗；不卡住标题栏或鼠标操作。
- [ ] B07 多窗口并行生成/改名/删除同一会话，无丢数据或旧状态覆盖。

## C. 聊天业务与 API

- [ ] C01 有效 API Key 验证；错误/过期 Key 提示可诊断但不泄露密钥。
- [ ] C02 逐字/逐事件流式输出 SSE，无乱码、丢事件或无故停顿。
- [ ] C03 取消中止底层网络任务；断网/超时/429/5xx/401 分别正确处理。
- [ ] C04 新建、删改、标题、历史、上下文消息分支、重新生成、续写、深度思考完整。
- [ ] C05 联网搜索/链接阅读/来源引用/搜索状态与 Windows 一致。
- [ ] C06 图片、PDF、各类支持附件上传/预览、拖拽、粘贴和失败重试。
- [ ] C07 Markdown/代码高亮/数学公式/Mermaid/表格、超长回答显示正确。
- [ ] C08 中文/英文切换和字体、中文输入法候选、复制/粘贴无错位。

## D. 音频与权限

- [ ] D01 首次录音正确触发系统/站点权限提示，拒绝后可从系统设置恢复。
- [ ] D02 WAV 16kHz 录制到 ASR 正确；取消录制释放麦克风。
- [ ] D03 TTS PCM 24kHz 回放正确，停止/切换会话不会残留声音。
- [ ] D04 无麦克风、权限被撤销、无网和中断均有清楚错误说明。

## E. 数据 / 备份 / 安全

- [ ] E01 会话与原附件原件不丢，退出、重启、崩溃、升级后正确恢复。
- [ ] E02 从 Windows 原始 v3 ZIP 导入保留消息树和图片，说明非图片原件限制。
- [ ] E03 v4 完整备份包含所有本地附件；校验故障原子回滚，旧会话不丢。
- [ ] E04 IndexedDB→SQLite 迁移分批校验 ID/条数/hash，失败不清空旧库。
- [ ] E05 Mac API Key 用私有本地文件保存，刷新、新窗口和重启均沿用配置；启动无需钥匙串授权，网页持久化存储、ZIP 和日志不含明文。
- [ ] E06 外部网页、iframe、路径穿越不能调用任意 Native Bridge 系统能力。
- [ ] E07 文件选择/拖拽/下载保留文件名且允许取消，Zip-slip / oversized archive 被拒绝。
- [ ] E08 存储配额不足/磁盘只读/损坏/错误同步时，不静默覆盖用户聊天。

## F. 局域网同步

- [ ] F01 Mac↔Windows 在同 Wi-Fi 自动发现、双向配对、双向同步。
- [ ] F02 Mac↔Android 在同 Wi-Fi 自动发现、双向配对、双向同步。
- [ ] F03 Windows↔Android 同协议兼容（完整跨端版本）。
- [ ] F04 未配对设备/伪造消息无法读取数据；撤销后立即拒绝。
- [ ] F05 双端离线修改、编辑分支、重命名、删除 tombstone、草稿策略正确。
- [ ] F06 大附件断点恢复、重复请求幂等、网络切换、设备睡眠、重连正确。
- [ ] F07 UI 显示最近同步时间、同步状态和冲突，错误可重试。

## G. 更新/发布与性能

- [ ] G01 Sparkle 正式 feed 可检测测试新版；签名不正确的更新拒绝安装。
- [ ] G02 从 1.0.0-beta 到 1.0.0 更新完成且原数据、Key、窗口配置不丢。
- [ ] G03 菜单栏检查更新、自动检查开关、下载进度/失败重试正确。
- [ ] G04 1 万+ 条消息/大量附件列表可用；无不可接受的内存增长。
- [ ] G05 日志脱敏、诊断导出不会包含 Key 与私有聊天内容。
- [ ] G06 无网络/代理/低磁盘/低内存环境功能有明确回退提示。

## 发布门禁

所有 A–G 必做用例勾选且附对应 PR/测试报告/平台证据才能发 V1。当前工程骨架**未通过任何 Mac 真机用例**。
