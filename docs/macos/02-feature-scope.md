# V1 全量功能范围（不是 Roadmap）

图例：`壳` = 当前有初始实现/代码框架；`待集成` = 依赖 Windows 网页源代码；`待开发` = 无真实业务实现。**状态是本脚手架实际状态，不是发布范围**。

| 领域 | V1 交付要求 | 当前骨架 | 必要验收 |
|---|---|---|---|
| UI | 保留 Windows 自定义全部 DeepSeek 网页聊天功能和样式 | 待集成 | 与 Windows 逐屏功能对照 |
| 对话 | 新建/重命名/删除/搜索、分支/编辑、继续/重新生成、停止 | 待集成 | 状态树与历史一致 |
| AI | 深度思考、搜索、网页阅读、引用、流式 SSE、附件、模型设置 | 待集成 + Native 网络待开发 | 完成真实 DeepSeek API 用例 |
| Markdown | 代码高亮、KaTeX、Mermaid、图片及附件浏览 | 待集成 | 不乱码、不截断、不 XSS |
| 语音 | 实时录制、ASR、TTS、进度/取消、权限、频谱 UI | Mac 权限壳；其余待集成 | 首次授权/拒绝/再授权 |
| 多语言 | 中文/英文、深色/浅色/跟随系统 | Web 待集成；原生读系统主题有壳 | 切换即生效 |
| 窗口 | macOS 原生红黄绿、全屏/尺寸记忆、Dock、菜单栏 | 初始壳 | 关闭窗口不退出；重新打开 |
| 多窗口 | 多聊天窗口同时工作，数据广播、草稿隔离 | WindowGroup 壳；一致性待开发 | 两窗口并发更新不覆盖 |
| 快捷键 | Cmd+, / Cmd+N / Cmd+W / Cmd+Q / Cmd+Shift+N 等 | 待开发 | 不与输入/页面冲突 |
| 文件 | 选择、拖拽、预览、打开、保存、ZIP 下载 | 基础 picker/download 壳 | 附件完整，取消无异常 |
| 本地数据 | SQLite + 文件原件 + 事务 + 多窗口持久化 | 待开发 | 更新/崩溃/断电不丢数据 |
| 导入导出 | Windows→Mac v3 兼容，v4 完整备份（保留文件） | 待开发 | 校验后原子提交/失败回滚 |
| 密钥 | Mac 本地凭据、原生 API 网络层 | 用户专属凭据文件 | 重启恢复；运行期间窗口共享状态；持久化前端存储、日志、ZIP 无密钥 |
| 系统 | Mac 原生关于、更新、菜单栏图标、登录启动 | 关于/菜单栏/更新接线壳 | 符合系统交互习惯 |
| 自动更新 | Sparkle 签名 feed、检查/下载/安装/版本验证 | 接线壳 | 旧版→新版成功且数据不丢 |
| 安装 | Universal DMG，签名公证，可卸载 | XcodeGen/脚本壳 | 双 CPU 架构与 Gatekeeper |
| LAN 同步 | Bonjour、配对、认证、差异同步、删除冲突、附件、离线恢复 | Bonjour 浏览壳；协议草案 | Win/Mac/Android 三端互通 |
| 安全 | 最小权限、Bridge 来源白名单、防注入、数据备份 | 部分基础安全壳 | 安全测试报告 |
| 诊断 | 脱敏日志、错误分级、诊断 ZIP、用户导出 | 待开发 | 不包含 Key、聊天正文默认隐藏 |

**V1 发布时这些都是必需能力，不能将任何“待开发”标为完成；由负责接手的 AI 逐项开发和回填测试证据。**
